# バズリス v0.27.8 STABILITY AUDIT

## 今回の目的
新要素追加前の安定化と、全46カードの監査。

## 追加・修正

### カード・セーブ監査
ホームに「カード・セーブ監査」を追加。

検査対象:
- 全カードのID重複
- 名前、アイコン、コスト、効果、play定義
- 1回限りキーの重複
- 直接スコアカードの基礎式登録
- 代表戦況での予測式
- 長いカード名と効果
- 実際のカード表示幅
- 所持カード、編成、レリック参照
- 予測スコアと実獲得スコアの差分

監査結果はJSONとして書き出せる。

### セーブ修復
saveVersionを28へ更新。

- 更新前セーブをブラウザ内へバックアップ
- 不明カード・レリックは削除せず隔離
- 重複UIDを再発行
- 無効なデッキ参照を除去
- 存在しない装着レリック参照を除去
- 復活したカード定義は隔離領域から自動復元

### 操作安定化
- カード処理中の二重プレイを防止
- ドラッグ終了後の遅延タップを抑制
- 予測値と実獲得値が1%以上ずれた場合、最大30件まで診断記録
