# バズリス v0.27.7 SCREEN GUARD

## 優先修正

### 画面二重表示
- `#gameScreen:not(.active)` を必ず非表示
- ホーム表示時はゲーム画面の操作判定も無効化
- ゲーム表示時はホーム側の active を明示的に解除

### ログ・カード確認ボタン
- 手札下の固定丸ボタンを撤去
- ゲーム上部のタイトルツールへ移動
- カード操作領域との重なりを解消

### カード解析欄
- 効果欄を2行表示へ変更
- 完全な効果文を title / aria-label に保持
- 長文時は自動で少し縮小
- 未ドラッグ時の表示を「選択中」に修正

### 全カード可読性対策
- 名前、基礎式、強化、予測、補助効果を表示後に再計測
- はみ出す項目を2段階で自動縮小
- 残った見切れ候補を `window.__buzzCardAudit` に記録
- 詳細画面では全文を保持

### デッキ構築
- カード一覧から倍率を撤去
- カード詳細からも倍率・戦闘予測を撤去
- カードごとの重複操作案内を非表示
