# バズリス v0.27.3 ACTION FLOW

## 主な更新
- 常時点滅を増やさず、背景を3層の電子空間へ強化
- カード使用時、カードのゴーストが場へ飛び、着地バーストを発生
- トークン獲得演出を強化
  - アイコンを大きく
  - 飛行時間を延長
  - 小さな軌跡と粒子を追加
  - 到着先ステータスが短く反応
- 手札に新しく入ったカードへドロー演出を追加
- 炎上獲得が大きい時、炎上欄だけ軽く異常感を出す
- モーションOFF / 端末の動き抑制設定に対応
