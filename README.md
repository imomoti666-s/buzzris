# バズリス v0.26.2 Safe Modal + Notice

## 更新内容
- カード詳細を開いた直後、同じタップで分解ボタンなどが誤爆しないようにガードを追加
- alert系の白いブラウザ通知を、ゲーム内の暗緑モーダル通知へ置き換え
- レリック生成、カード生成、素材不足、合成結果などがゲーム内で表示される

## GitHubへ上げる場所
リポジトリ buzzris のルートに以下を上書きしてください。

- index.html
- manifest.webmanifest
- service-worker.js
- README.md

icons フォルダ内には以下を上書きしてください。

- icon-192.png
- icon-512.png
- icon-maskable-512.png

## 反映されない場合
ゲーム内の「最新版に更新」を押してください。
