# バズリス v0.27.6 FIXED DOCK

## 主な修正

### 1. カード名と視覚情報の監査
- 長いカード名が見切れにくいよう、ゲーム中・デッキ構築中ともに2行表示へ調整
- 文字数に応じて自動で少し縮小
- 手札カードは「基礎 / 予測」のみに絞り、情報密度を維持しつつ読みやすくした

### 2. デッキ構築画面
- 倍率(③)を撤去
- 表示を `①基礎 / ②強化` に整理
- 追加で主要な補助効果を1行だけ表示

### 3. ゲーム画面の下部固定
- `場 → カード詳細 → 手札 → ターン終了 / 撤退` を下部ドックとして固定
- 持続効果や臨界予告が増減しても、手札の位置が動かない構成に変更
- 上部の情報は別スクロール領域に分離

### 4. 場の安定化
- 場の高さを固定
- 投稿済みカードは横スクロールで保持
